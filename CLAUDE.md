# Проект: предсказание незачёта (хакатон, кейс 6)

## Данные
student-por.csv (649×33), student-mat.csv (395×33), разделитель `;`.
Целевая: y = (G3 < 10). Дисбаланс 15.4 % на португальском.

## Незыблемые правила
- G3 никогда не в признаках. Ассерт обязателен.
- Рабочий уровень — без G1/G2: список нужен в середине семестра.
- Все метрики с разбросом по фолдам. Accuracy не использовать.
- Сравнение вариантов — только парное, на одних и тех же фолдах.
- Отбор на фолдах seed=0, подтверждение на seed=1.
- Permutation importance только out-of-fold.
- Только scikit-learn, все random_state = 42.

## Запуск
Окружение — `.venv` (Python 3.11.9), зависимости в `requirements.txt`.
Первый прогон ноутбука ≈ 15–20 минут (сетка гиперпараметров), повторный — под минуту.
